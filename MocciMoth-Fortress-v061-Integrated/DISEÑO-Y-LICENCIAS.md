# MocciMoth Fortress — Edición Boutique

## Diseño
Fondo marfil, superficies crema, navegación clara y títulos Philosopher. El logotipo utiliza Caramel and Vanilla. Monimer se utiliza únicamente para detalles editoriales, y Quicksand permanece como fuente de interfaz de respaldo (si está instalada; de lo contrario, se usa la fuente del sistema).

## Licencias
- Philosopher: se incluye con licencia OFL, ver archivo `assets/fonts/OFL.txt`.
- Monimer Serif: **PERSONAL USE ONLY**. No se debe utilizar en un sitio comercial o público sin la licencia apropiada. Leer `public/assets/fonts/READ_BEFORE_ANY_USE.txt`. Si no tenés licencia para ese uso, eliminá el archivo OTF y la regla `@font-face` correspondiente; la web usará Philosopher como alternativa.
- Caramel and Vanilla: el ZIP suministrado no incluye una licencia. Verificá los derechos de uso antes de publicar el sitio.

## Seguridad
Se conservan las correcciones de Fortress v0.5 Alpha. Esta edición cambia principalmente la presentación; **no incorpora MFA ni HTTPS**. No exponer en una red compartida hasta configurarlos y probarlos. El checkout sigue identificado como demostración, sin cobros reales.

## Arranque
`npm.cmd test` y `npm.cmd start` desde la carpeta raíz.
